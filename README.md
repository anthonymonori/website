# monori.me
![Build & Deploy](https://github.com/anthonymonori/monori-me/workflows/Build%20&%20Deploy/badge.svg?branch=master)

## Install

```Shell
gem install bundler
bundle install
```

**Note:** This project uses Mermaid diagrams rendered at build time. See [SETUP.md](SETUP.md) for additional dependencies (Node.js, mermaid-cli).

## Build

```Shell
jekyll build --watch
```

## Deploy locally

```Shell
jekyll serve
```
